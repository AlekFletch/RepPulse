# RepPulse: сборка в DevEco Studio и установка на Watch Fit 4

Пошаговая инструкция для первого запуска на часах. Шаги, которые я не смог проверить по официальной документации, помечены **⚠**. Если на них интерфейс выглядит иначе, пришлите скриншот.

---

## Что понадобится

- ПК с DevEco Studio 6.1 (уже установлена) и клоном репозитория.
- Huawei Watch Fit 4, сопряжённые с телефоном на Android.
- Приложение Huawei Health на телефоне.
- USB-кабель для телефона, чтобы скопировать файл на него.
- Аккаунт Huawei Developer с пройденной верификацией: https://developer.huawei.com/consumer/en/

---

## Шаг 0. Получить проект

```bash
git clone https://github.com/AlekFletch/RepPulse.git
```

Если проект уже лежит в `C:\Claude\RepPulse`, просто выполните в нём `git pull`.

---

## Шаг 1. Открыть проект в DevEco и проверить в Previewer

1. DevEco Studio → **File → Open** → выбрать папку `RepPulse` (корень, где лежит `build-profile.json5`) → **Trust Project**.
2. DevEco запустит **Sync** (hvigor). Дождитесь окончания: прогресс виден внизу справа, результат — во вкладке **Build**.
   - Если IDE предлагает обновить или мигрировать файлы проекта (modelVersion, hvigor), соглашайтесь. Потом пришлите мне вывод `git diff`, я закоммичу изменения.
   - Если пишет, что SDK не найден: **File → Settings → SDK** и отметить нужную версию HarmonyOS SDK.
3. Откройте `entry/src/main/js/default/pages/index/index.hml`, затем **View → Tool Windows → Previewer**.
   - Должна появиться главная с заголовком «Тренировка», иконками «Приседания» и «Отжимания», заглушкой «—» у «Истории» и кнопкой «Диагностика».
   - В Previewer и симуляторе датчики **не работают**. Здесь проверяем только, что разметка собирается.
4. Сделайте скриншот Previewer. Он пригодится для настройки размеров на Этапе 3.

✅ **Результат:** проект синхронизирован, Previewer показывает главный экран.

---

## Шаг 2. Включить режим разработчика на часах ⚠

1. Часы: **Настройки → О часах** (или «Система → О часах»).
2. Нажмите 5–7 раз подряд на **номер версии ПО**, пока не появится сообщение о включении режима разработчика.
3. В разделе **«Для разработчиков»** включите главный переключатель. На Watch Fit 4 (прошивка 6.1.0.117, API 6.1.0(23)) других нужных пунктов там нет: **HDC-отладки на lite-часах нет, и она не нужна**. HAP ставится с телефона через Health и DevEco Assistant по Bluetooth.
4. Запишите **версию ПО и версию API часов**: они нужны, чтобы выбрать правильный уровень API.

---

## Шаг 3. Установить DevEco Assistant на телефон и узнать UDID часов ⚠

1. На телефоне установите **DevEco Assistant** (китайское название «应用调测助手»). Ищите в Huawei AppGallery на телефоне.
2. Откройте его, выдайте запрошенные разрешения. Приложение Health должно быть запущено, часы — подключены.
3. DevEco Assistant покажет подключённые часы и их **UDID**. Скопируйте UDID: он нужен в AppGallery Connect.

> Если DevEco Assistant не находится в AppGallery, напишите, какой у вас телефон и версия Android/EMUI. Будем искать другой путь.

---

## Шаг 4. Сгенерировать ключ и CSR в DevEco

Для lite wearable автоматическая подпись не поддерживается, поэтому подписываем вручную.

1. Создайте папку **вне репозитория**, например `C:\RepPulse-signing\`. Файлы подписи **никогда не коммитим**.
2. DevEco: **Build → Generate Key and CSR**.
3. **Key store file** → *New*:
   - путь: `C:\RepPulse-signing\reppulse.p12`;
   - пароль хранилища: придумайте и сохраните в менеджер паролей.
4. **Alias:** `reppulse`, пароль ключа — можно тот же. Validity — по умолчанию.
5. **CSR file:** `C:\RepPulse-signing\reppulse.csr` → **Finish**.

✅ **Результат:** в папке лежат `reppulse.p12` и `reppulse.csr`.

---

## Шаг 5. AppGallery Connect: сертификат, устройство, приложение, профиль ⚠

Откройте https://developer.huawei.com/consumer/en/service/josp/agc/index.html → **Certificates, app IDs, and profiles** (в русском интерфейсе — «Сертификаты, ID приложений и профили»).

### 5.1. Debug-сертификат
**Certificates → New certificate:**
- тип **Debug certificate**;
- имя — любое, например `reppulse-debug`;
- загрузить `reppulse.csr` → **Submit**.

Скачайте получившийся `.cer` в `C:\RepPulse-signing\reppulse-debug.cer`.

### 5.2. Устройство
**Devices → Add device:**
- тип — часы / wearable;
- имя — `Watch Fit 4`;
- **UDID** — из шага 3.

### 5.3. ID приложения
**App IDs → New:**
- тип — HarmonyOS-приложение;
- если предложен выбор устройства, выбирайте **Lite wearable** (или «Watch»);
- **Bundle name / package name** — строго `com.alekfletch.reppulse`: так он записан в `entry/src/main/config.json`.

> Если в AGC нужно сначала создать проект: **My projects → Add project** → `RepPulse`, затем добавить в него приложение с тем же bundle name.

### 5.4. Debug-профиль
**Profiles → Add:**
- приложение — `com.alekfletch.reppulse`;
- тип — **Debug**;
- сертификат — из 5.1;
- устройство — из 5.2.

Скачайте `.p7b` в `C:\RepPulse-signing\reppulse-debug.p7b`.

✅ **Результат:** в `C:\RepPulse-signing\` лежат четыре файла: `.p12`, `.csr`, `.cer` и `.p7b`.

---

## Шаг 6. Прописать подпись в проекте

1. DevEco: **File → Project Structure → Project → Signing Configs**.
2. **Снимите** галочку *Automatically generate signature*.
3. Заполните поля:

| Поле | Значение |
|---|---|
| Store file | `C:\RepPulse-signing\reppulse.p12` |
| Store password | пароль из шага 4 |
| Key alias | `reppulse` |
| Key password | пароль ключа |
| Sign alg | `SHA256withECDSA` (по умолчанию) |
| Profile file | `C:\RepPulse-signing\reppulse-debug.p7b` |
| Certpath file | `C:\RepPulse-signing\reppulse-debug.cer` |

4. **OK**. DevEco запишет конфигурацию в `build-profile.json5`, пароли — в зашифрованном виде.

> ⚠ **Важно:** после этого шага **не коммитьте** `build-profile.json5` с заполненным `signingConfigs`: там пути и зашифрованные пароли. Перед коммитом выполните `git checkout -- build-profile.json5` для этого блока или просто не добавляйте файл. На Этапе 3 я вынесу подпись в отдельный локальный файл, чтобы это не мешало.

---

## Шаг 7. Собрать HAP

1. **Build → Build Hap(s)/APP(s) → Build Hap(s)**.
2. Во вкладке **Build** должно появиться `BUILD SUCCESSFUL`.
3. Подписанный файл лежит в `entry\build\default\outputs\default\`. Нужен тот, в имени которого есть `signed`, например `entry-default-signed.hap`.

Если сборка упала, скопируйте мне **целиком** текст ошибки из вкладки Build.

---

## Шаг 8. Установить на часы ⚠

1. Подключите телефон к ПК по USB в режиме передачи файлов.
2. Во внутренней памяти телефона создайте папку **`haps`** в корне (путь `/sdcard/haps/`) и скопируйте туда `entry-default-signed.hap`.
3. Откройте **DevEco Assistant** на телефоне → выберите HAP → **Установить** (Install). Health должен работать, часы — быть рядом и подключены.
4. На часах в списке приложений появится **RepPulse** с нашей иконкой.

### Если установка не удалась

| Ошибка | Что делать |
|---|---|
| **Error 40** | Скорее всего, прошивка не принимает наш уровень API. В `build-profile.json5` поменяйте `"compatibleSdkVersion": "5.0.0(12)"` на `"4.0.0(10)"`, пересоберите (шаг 7) и повторите. Сообщите мне, какой вариант сработал. |
| Ошибка подписи / профиля | Проверьте, что UDID в AGC совпадает с UDID из DevEco Assistant и что bundle name — ровно `com.alekfletch.reppulse`. |
| Любая другая | Скриншот экрана DevEco Assistant. |

## Шаг 9. Проверка на часах: «Диагностика»

Откройте RepPulse → прокрутите вниз → **«Диагностика»**. Экран не должен гаснуть, пока страница открыта.

Пройдите проверки и запишите результаты:

| # | Действие | Что записать |
|---|---|---|
| 1 | Положите часы неподвижно экраном вверх на 5 секунд | строку **A** (три числа) — ожидаем примерно `0 0 9.8`, если единицы — м/с² |
| 2 | Не трогайте часы | строку **«Частота: … Hz, G=…»** — сколько Гц и растёт ли число G |
| 3 | Покрутите запястьем | меняется ли строка **G** (гироскоп) и какие числа видны при быстром повороте (≈1–5 — рад/с, ≈50–300 — градусы/с) |
| 4 | «Вибро коротко», затем «Вибро длинно» | ощущается ли разница, примерная длительность каждой |
| 5 | «Тест файла» | результат строкой (`OK file N/N` или текст ошибки) |
| 6 | «Тест storage» | результат строкой (`OK kv 200/200` или ошибку) |
| 7 | Во время диагностики нажмите боковую кнопку и вернитесь в приложение | что произошло: продолжило работу, открылось с главной или закрылось |
| 8 | Пусть придёт уведомление (например, сообщение на телефон) при открытой диагностике | как повело себя приложение |

**Прислать мне:**
- версию ПО часов;
- рабочий `compatibleSdkVersion`;
- ответы по пунктам 1–8.
