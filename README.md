# RepPulse: Push-Up & Squat Counter

Автономное приложение для **Huawei Watch Fit 4 / Fit 4 Pro**, которое автоматически считает приседания и отжимания, ведёт подходы и отдых, подаёт вибросигналы и хранит статистику прямо на часах.

> Статус (2026-09-24): **Этап 5 из 6**. Все экраны, тренировки (свободный режим, на время, подходы с отдыхом), история, настройки, автоматический подсчёт повторов и калибровка готовы и проверены на синтетике и в симуляторе; настройки сохраняются в файл. 164 теста, включая сквозные сценарии. Дальше: проверка на часах по чек-листу [docs/08 §4](docs/08-stage5.md) и доводка порогов по реальным данным; Этап 6 — README для AppGallery и политика конфиденциальности.

## Платформа

Watch Fit 4 относится к **lite wearable**. Приложение написано на JS UI (HML/CSS/JS, FA-модель) в DevEco Studio. ArkTS на этих часах не поддерживается. Подробности и источники — в [docs/01-platform-verification.md](docs/01-platform-verification.md).

## Быстрый старт

**Проверка логики** (Node.js 18+):

```
npm install
npm test               # 157 тестов: логика, детекция на синтетике, хранилище
npm run lint           # ESLint с ограничениями lite JS (нет RegExp, class, spread и т. п.)
npm run check:bundles  # после сборки: каждая страница ≤ 48 КБ
```

**Симулятор часов без DevEco:** `python tools/simulator.py --out shots "wait 2" "shot home" "tap 200 145"` — касания, свайпы, скриншоты и лог движка ([docs/06 §4](docs/06-stage3.md)).

**Сборка для часов:**
1. Открыть папку в DevEco Studio 6.1.
2. Выполнить Sync.
3. Указать подпись в File → Project Structure → Signing Configs (debug-сертификат AGC с UDID часов; файлы подписи в git не коммитятся).
4. Выполнить Build → Build Hap(s) или собрать из консоли (команда в [docs/05 §3](docs/05-status-handoff.md)). Задача `RepPulseMinifyLiteJS` в `entry/hvigorfile.ts` сама минифицирует JS: без этого страницы не помещаются в лимиты часов.

Как установить сборку на часы, описано в [docs/01-platform-verification.md §9](docs/01-platform-verification.md).

После первой установки откройте на часах «Диагностика» и пройдите чек-лист из §12: частота датчиков, гироскоп, вибрация, файлы, storage.
